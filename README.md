# 小红书文案生成工作流

> 当前版本：`v1.0.0`。已完成同一 Dify 工作空间内的独立导入与脱敏运行验证、应用包内部隐私检查和 MIT 许可证配置。

## 项目简介

这是一个面向墙布、壁布等墙面装饰材料文案的 Dify 工作流应用包。使用者填写城市、小区、区域、核心产品、资料名称、环保认证标准、风格和材质等信息，工作流通过大语言模型生成小红书文案及英文 Midjourney 配图提示词。

本项目适合用于学习 Dify 工作流的导入、配置和基本测试，也可以作为同类文案工作流的参考模板。

**交付形式是 `.ifpkg` 应用包，不是可以双击独立运行的软件，也不是完整部署好的在线服务。**

## 发布内容说明

本发布版本包含原版的完整工作流，包括：

- 完整 `.ifpkg` 应用包；
- 工作流配置和完整系统提示词；
- 8 套风格模板、24 种材质英文映射、17 个场景映射及相关文案规则；
- 使用说明、脱敏测试示例和 MIT 许可证。

下载者可以查看、复制和修改上述提示词及配置。本仓库不包含发布者的 Dify 账号或工作空间，不公开 Web App 或 API，也不包含模型 API Key、调用额度、客户资料或其他账号凭据。使用者需要在自己的 Dify 环境中配置自己有权使用的模型资源，并承担相应的模型调用费用。

## 工作流结构

当前版本的主干流程为：

```text
用户输入 → LLM → 输出（text，String）
```

- 输入：8 个业务变量。
- 处理：1 个 LLM 节点。
- 输出：LLM 生成的文本字符串；本次验证输出包含中文文案和英文配图提示词。
- 当前画布没有独立的知识库检索节点。
- 不直接生成或发布图片，也不包含自动发布到小红书的功能。

## 运行要求

1. **Dify 1.18.0 或更高版本**：`.ifpkg` 应用包只能直接导入 Dify 1.18.0 及以后版本。
2. **可用的聊天模型**：原工作流画布中的模型显示为 `kimi-k3`（CHAT）。模型服务和调用额度不包含在本仓库中。
3. 如果导入后提示模型、插件或其他资源缺失，需要在你自己的 Dify 环境中安装或配置相应资源，也可以在 LLM 节点选择你拥有使用权限的兼容聊天模型。

**注意：更换模型可能改变生成效果，更换后应重新测试。模型 API Key 等凭据只填写在你自己的 Dify 环境中，不要提交到 GitHub。**

参考：[Dify 官方文档：导出和导入应用](https://docs.dify.ai/en/cloud/use-dify/workspace/export-import-apps)。

## 下载与导入

正式应用包：[`小红书文案生成工作流-v1.0.0.ifpkg`](./小红书文案生成工作流-v1.0.0.ifpkg)

版本发布页面：[`Releases`](https://github.com/xyctf/dify-xiaohongshu-copy-workflow/releases)

1. 从仓库文件列表或正式 Release 中下载上述 `.ifpkg` 应用包。
2. 打开 Dify **工作室首页**。
3. 选择“创建”→“Import App／导入应用”。
4. 上传下载的 `.ifpkg` 文件，按照页面提示检查缺失资源并完成导入。
5. 导入后应得到一个**独立的新应用**。检查模型配置，再使用 [`测试示例.md`](./测试示例.md) 进行测试。

**不要在已有应用内部使用“更新现有应用／覆盖导入”来做首次测试，以免替换该应用的草稿、名称、描述或图标。**

## 输入字段说明

| 变量名 | 显示名称 | 类型 | 是否必填 | 填写说明 |
|---|---|---|---|---|
| `city` | 城市 | 文本 | 必填 | 填写所在城市，例如“杭州”。 |
| `community` | 小区名 | 文本 | 必填 | 填写小区名称；公开测试时使用虚构名称。 |
| `district` | 区域名 | 文本 | 必填 | 填写所在区域，例如“西湖区”。 |
| `product` | 核心产品 | 文本 | 必填 | 填写墙布、壁布等需要介绍的核心产品，例如“无缝壁布”。 |
| `material` | 资料名称 | 文本 | 必填 | 填写本产品相关资料或营销资料的名称，例如“同款搭配清单”。 |
| `certification` | 环保认证标准 | 文本 | 可选 | 只填写真实、可核实的信息；没有依据时建议留空，不要编造认证。 |
| `style` | 风格 | 下拉选项 | 必填 | 从 8 个风格选项中选择，默认值为“治愈奶油风”。 |
| `texture` | 材质 | 下拉选项 | 必填 | 从 24 个材质选项中选择；默认值为空，需要手动选择。 |

## 基本测试

可以使用以下脱敏输入进行首次测试：

| 输入字段 | 测试值 |
|---|---|
| 城市 | 杭州 |
| 小区名 | 云栖示例小区 |
| 区域名 | 西湖区 |
| 核心产品 | 无缝壁布 |
| 资料名称 | 同款搭配清单 |
| 环保认证标准 | 留空 |
| 风格 | 治愈奶油风 |
| 材质 | 高精密 |

“云栖示例小区”是虚构测试名称，不需要把“虚构”二字输入工作流。

基本通过标准：

- 工作流能够完整运行，没有节点报错；
- 输出节点返回非空文本；
- 输出内容与主要产品、风格和材质等输入基本相关；
- 环保认证标准留空时，不应把未经提供的具体认证写成既成事实。

详细测试方法和真实验证记录见 [`测试示例.md`](./测试示例.md)。

## 使用限制与注意事项

- 生成结果由大语言模型产生，可能存在事实错误、夸大表达或不合适宣传用语，正式使用前必须人工审核。
- 模型可能创作输入中未提供的居住年限、使用体验、工艺细节或营销情境，例如“住了两年”；这些内容不能直接当作真实客户经历或产品事实发布。
- 对环保认证、手工工艺、使用效果等表述，应具有真实、可核实的依据，不要照搬生成结果。
- 本项目不保证生成内容一定符合小红书审核规则，也不保证阅读量、曝光量或营销效果。
- 不要在公开测试输入中填写客户姓名、电话、详细住址、账号信息或未公开商业资料。
- 公开仓库中不要上传 API Key、密码、私钥、访问令牌或其他凭据。
- 导出不包含秘密值并不等于应用包没有任何敏感内容；修改或重新导出后，仍应重新检查工作流配置、提示词、示例文本和附件。
